# VolunteerConnect 🤝

A full-stack modern platform connecting passionate volunteers with verified NGOs, featuring real-time opportunities, application workflows, automated certificate generation, attendance logging, and administrative oversight.

---

## 🚀 Live Cloud Deployment via Render Blueprint

This repository includes a native **Render Blueprint (`render.yaml`)** to deploy the complete infrastructure with zero manual service creation.

### One-Click Blueprint Deployment Steps:

1. **Push your code to GitHub** (see instructions below).
2. Log in to [Render Dashboard](https://dashboard.render.com/).
3. Click **New +** → **Blueprint**.
4. Connect your GitHub repository (`https://github.com/jahanafreen514/VolunteerConnect.git`).
5. Render will automatically parse `render.yaml` and provision two services:
   - **`volunteerconnect-api`** (Backend Web Service running Node.js + Express + Socket.io)
   - **`volunteerconnect-frontend`** (Frontend Static Site running React + Vite + Tailwind CSS)
6. Supply the required environment variables in the Render Dashboard:
   - `MONGODB_URI`: Your MongoDB connection string (e.g., from MongoDB Atlas)
   - `CLOUDINARY_CLOUD_NAME`: Cloudinary cloud name
   - `CLOUDINARY_API_KEY`: Cloudinary API key
   - `CLOUDINARY_API_SECRET`: Cloudinary API secret
   - `ADMIN_PASSWORD`: Secure password for initial admin seeding
7. Click **Apply**. Render will automatically build, deploy, and wire up the frontend and backend.

## 🛠️ Architecture & Tech Stack

- **Frontend**:
  - React 18, Vite 4, React Router 6
  - Tailwind CSS, Framer Motion, Lucide Icons
  - Axios, React Hook Form, Zod, Socket.io-client
- **Backend**:
  - Node.js, Express.js
  - MongoDB with Mongoose
  - JWT Authentication with HTTP cookies & Bearer tokens
  - Socket.io for live notifications and updates
  - Cloudinary for media and document uploads
  - Helmet & CORS security middleware
- **DevOps & Infrastructure**:
  - Render Infrastructure as Code (`render.yaml`)
  - GitHub Actions CI/CD Pipeline (`.github/workflows/production.yml`)

## ⚙️ Environment Variables Reference

### Backend (`backend/.env`):
| Variable | Description | Production (Render) |
|---|---|---|
| `PORT` | Server listening port | `5000` (or injected by Render) |
| `NODE_ENV` | Runtime environment | `production` |
| `MONGODB_URI` | MongoDB Atlas connection URI | Secure user secret |
| `JWT_SECRET` | Secret key for signing JWTs | Auto-generated by Render Blueprint |
| `CLIENT_URL` | Frontend URL for CORS & Socket.io | `https://volunteerconnect-frontend.onrender.com` |
| `CLOUDINARY_CLOUD_NAME` | Cloudinary credentials | Secure user secret |
| `CLOUDINARY_API_KEY` | Cloudinary API Key | Secure user secret |
| `CLOUDINARY_API_SECRET` | Cloudinary API Secret | Secure user secret |
| `ADMIN_EMAIL` | Default administrator email | `admin@volunteerconnect.com` |
| `ADMIN_PASSWORD` | Default administrator password | Secure user secret |

### Frontend (`frontend/.env`):
| Variable | Description | Production (Render) |
|---|---|---|
| `VITE_API_URL` | Base API URL | `https://volunteerconnect-api.onrender.com/api` |
| `VITE_SOCKET_URL` | Base Socket.io URL | `https://volunteerconnect-api.onrender.com` |

## 💻 Local Development Setup

### 1. Clone the repository
```bash
git clone https://github.com/jahanafreen514/VolunteerConnect.git
cd VolunteerConnect
```

### 2. Install all dependencies
```bash
npm run install:all
```

### 3. Configure local environment
- Copy `backend/.env.example` to `backend/.env` and update values.
- Copy `frontend/.env.example` to `frontend/.env` and update values.

### 4. Seed initial Admin user
```bash
npm run seed:admin
```

### 5. Run both servers
Open two terminals or run:
```bash
# Terminal 1: Backend API (http://localhost:5000)
npm run dev:backend

# Terminal 2: Frontend Client (http://localhost:5173)
npm run dev:frontend
```
